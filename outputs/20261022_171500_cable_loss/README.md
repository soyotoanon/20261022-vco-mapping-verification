# 通路线损测量（信号发生器 → 线缆+转接头 → 频谱仪）

日期：2026-10-22

方法：DG5352 输出已知幅度正弦波（0 dBm = 0.632 Vpp，50Ω 负载匹配），
走 VCO→频谱仪 的同一根线缆（含全部转接头），DSA815 读取轨迹峰值。

## 结果

- 100 MHz 处线损 ≈ **0.66 dB**（电压比 0.927）
- 50~150 MHz 范围内 0.63~0.93 dB，基本平坦
- 幅度线性良好（-20/-10/-3/0 dBm 四档损耗一致）

## 对 0.77× 结论的修正

VCO AM 映射实测为 DDS 显示值的 0.77×（电压比，即 -2.3 dB），分解为：

| 环节 | 损耗 | 电压比 |
|---|---|---|
| 线缆+转接头+频谱仪读数 | -0.66 dB | 0.927 |
| **VCO 模块本身（实际输出 < DDS 显示值）** | **-1.6 dB** | **0.83** |
| 合计 | -2.3 dB | 0.77 |

结论：0.77× 不全是线损。线损只占 0.66 dB；其余 ~1.6 dB 是
VCO/DDS 模块的实际输出低于软件显示值（模块校准偏差）。

## 备注

- 读数采用 :TRAC? TRACE1 轨迹法。该台 DSA815 的 :CALC:MARK1:MAX
  标记峰值搜索在发送过 :FREQ:STAR/STOP 后会停在扫宽边缘读噪底
  （固件 bug），vco_mapping_app.py 已改用轨迹法。
- amplitude_linearity 数据见首次测量记录：0.0632/0.2/0.447/0.632 Vpp
  四档损耗分别为 0.71/0.56/0.58/0.65 dB。
