# PI 带宽优化记录

## 模型引导优化（2026-10-23 晚场，Kimi）

**方法**：不再盲扫参数。先从一次同轮扫频提取被控对象模型 |P(f)| 与相位（无需相位参考：由 |S| 与 |L|=|C||P| 反解环路相位），再用模型数值搜索 (Kp, Ki, fs)，最后只把预测最优的三组上板验证。流程脚本：`wo/work/sysid_sweep_a.py`、`model_fit_opt.py`、`verify_candidates.py`、`full_sweeps_v.py`、`plot_result.py`。

**被控对象模型**（DAC 码→PD ADC 码，5 MHz 环路更新）：

```
P(f) = B / (1 + j·f/fp) · exp(−j·2π·f·τ),   fp ≈ 111 kHz, τ ≈ 5.3–5.6 μs
```

- τ≈5.5 μs 的纯延迟是带宽与高频峰的共同根源；数字链路延迟不足 1 μs，延迟主体在模拟链（DDS 模拟口 / AOM 声波渡越）。五组不同 (Kp,Ki) 的历史数据反解出同一条相位曲线，模型预测与实测偏差普遍 <0.5 dB（10 kHz 处 <0.25 dB）。
- **B 在小时尺度上漂移 ±40%**（同日 0.0376 → 0.0226 → 0.0302），直流工作点不变但小信号增益变化——这解释了「C4 复测失效」：不是光路被破坏，也不是反馈方向问题。任何定参数设计的带宽和峰值都会随 B 同步摆动。
- Ki 寄存器上限为 1/采样（A624 格式），Ki≤1 时延迟系统不存在「高增益无害区」；数值优化确认可加 rolloff 滤波器收益很小，未改固件。

**本轮三组模型引导候选（同轮实测，0.0836 Vpp，B≈0.030）**：

| 候选 | Kp | Ki/采样 | 10 kHz | 实测带宽 | 已测峰值 |
|---|---:|---:|---:|---:|---:|
| C19 (V1) | 10.5 | 0.658 | −4.58 dB | 11.42 kHz | +4.46 dB @ 48 kHz |
| C20 (V2) | 14.0 | 0.858 | −6.37 dB | **15.38 kHz** | +6.24 dB @ 48 kHz |
| **C21 (V3)** | **12.0** | **0.75** | **−5.37 dB** | **13.51 kHz** | +5.62 dB @ 48 kHz |

**当前选择 V3(C21)**：在观测到的增益漂移全范围内（B=0.0226~0.0376），模型预计其 10 kHz 抑制保持 −3.5…−7.1 dB（始终达标），带宽 10.8~16.2 kHz；C4/V1 在低增益端不达标（−2.1/−2.8 dB）。V2 带宽最大但高增益端峰值约 +8 dB，留作激进备选。若追求更低高频峰，需先压物理延迟（AOM 渡越 / DDS 链路），不是继续调 PI。
