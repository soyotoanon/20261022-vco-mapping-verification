# A624 PI 增益格式

原 A623 Flash 未改动。A624 是本次临时加载的增益扩展固件。

- 0x1A：最高位为 0 时，沿用 Kp = 2^(-寄存器值)，15～31 表示比例项关闭。最高位为 1 时，Kp = 低15位 / 256，支持 0～127.996。
- 0x1B：最高位为 0 时，沿用每采样 Ki = 2^(-寄存器值)，23～63 表示积分增量关闭。最高位为 1 时，每采样 Ki = 低15位 / 32768，支持 0～0.999969。
- 注意：旧格式 Ki 寄存器写入 0 表示 Ki=1，不表示关闭积分。关闭积分增量可写入 0x8000；已有积分状态不会因此清零。
- Kp=12 的寄存器值为 0x8C00；Kp=24 为 0x9800；Ki=0.5 可沿用旧格式寄存器值1。
- ADC_HALF=4 对应5 MHz；ADC_HALF=3 对应6.25 MHz。Ki为每次有效采样的增益，因此采样率改变会改变实际积分速度。
- UART 写入后必须读回验证。写固定增益前必须确认固件ID 0x3F 为 0xA624；旧固件会截断这些寄存器值。
- 目标光强仍通过运行时寄存器0x18设置；不需要重编译。增益扩展没有改变输出限幅、积分限幅和反馈方向的定义。

本次扩展保留Q9积分状态。较大Ki下小误差有非零增量，但很小Ki的截断问题仍然存在，不能宣称已普遍消除积分量化死区。
