## 后续光强输入 UI 的约定

用户希望输入物理光强，通过既有 PD/ADC 标定反算目标 ADC 码。SETPOINT 是反馈需要维持的测量目标；DAC BIAS 是执行器的起始基准，PI 输出是在它上面加减修正。DAC–光强标定可帮助选基准，但不能把 DAC 码直接写进 ADC 目标寄存器。该物理单位输入功能留待本次任务之后，不混入当前测量界面。
