# 光强反馈性能测量

本版本保留原 PI 算法，增加 FPGA 输出端正弦注入、定时采样缓存与简洁的 Windows 测量界面。

## 启动和测量

本机双击 `start_measurement.cmd`。其他机器安装 Python 及 `host/performance/requirements.txt`，运行 `python host/performance/app.py`。串口默认 COM9，115200；测量期间关闭其他占用串口的 PID 程序。

1. 在当前光强下使闭环稳定。点击「连接」。目标和增益仍可通过原 UART 寄存器在线修改，不需要重新烧录。
2. 「① 测噪声谱」：先按提示遮住 PD 入光，测暗场噪声底，再恢复入光。程序在保持当前输出的开环与正常闭环之间切换，逐段更新三条噪声谱。不要切断 PD 电源或拔线来代替遮光。
3. 「② 计算 RMS」：对输入频段内的单边 RIN 积分，显示开闭环相对 RMS。默认 0.5 Hz–100 kHz；论文必须同时注明积分频段。
4. 「③ 单幅扫频」：默认 12 个对数频点。在 PI 输出之后、最终限幅之前加同样的正弦扰动，分别测开闭环响应振幅，实时更新比值。默认扰动 0.084 Vpp。若转折落在两个相距较远的频点之间，缩小频率范围重测；粗扫插值不能当作精密带宽。
5. 原始记录、参数和 CSV/JSON 自动保存在 `measurements/日期时间/`；「保存图 / 查看数据」另存 PNG、PDF 并打开目录。每次重新测量会追加原始记录并更新本次汇总 CSV；要保留独立汇总，请重新打开界面建立新会话。

暗场阶段每读完一段即显示 ADC码²/Hz 的噪声谱；这时尚未获得配对的带光均值，因此不标成 RIN。采集时显示倒计时和段数，期间保持完全遮光，直到「恢复光照」提示。暗场记录出现明显跳变或各段均值相差超过 10 ADC 码会停止计算，原始数据仍保存。这是异常筛查，不能代替确认 PD 确实完全遮光。

「扫频扰动 / Vpp」用于第③步的单幅扫频，表示 DAC 输出到 VCO 模拟控制端的正弦峰峰值。选幅度时可先用约 0.084 Vpp，再用约 0.042 Vpp 重复同一频段；只要都能分辨且抑制比在测量不确定度内一致，就有小信号线性的证据。过小而不可检出时才逐步增加；出现限幅或抑制比随幅度改变，则不能将其混成一个与幅度无关的带宽。实际相对光强扰动由开环正弦 ADC 振幅除以扣除暗场后的平均 ADC 信号计算。

采集在 FPGA 中定时完成，每段 8192 点；115200 串口只传输已经采好的缓存。读回一段约需数十秒，低频采集另需约 27 秒，完整多频段噪声测量需要数分钟。实时显示是逐段/逐频点更新，不是连续视频式刷新。

## 扰动电压换算

界面输入、热图纵轴、悬停提示统一使用 Vpp；内部码值只保留在原始数据中用于复现。采用原仓库 2026-10-22 已记录的万用表直流两点标定：V=0.0006533×(code−8198)。正弦峰峰值换算为 Vpp=2×0.0006533×峰值码；64 码对应 0.0836224 Vpp。零点不影响峰峰值。输入值会取整为硬件可实现的设定，显示和 CSV 的 amplitude_Vpp 使用取整后的值，最小幅度步进约 0.0013066 Vpp。

来源：[原仓库标定记录](https://github.com/soyotoanon/20261022-vco-mapping-verification/blob/102e8e9d3b896aec625270f646f107e312208e29/README.md)。这是基于既有直流标定的设定电压换算，尚未用示波器逐频率测量交流幅度，亦未补偿外部模拟链的频响；正弦数字量化还可能引入约一 LSB 的峰峰值差异。session.json 和 grid.json 保存标定来源、斜率和定义。

## 频率 × 扰动幅度热力图

新增「④ 频率×幅度」：频率使用上面的上下限；新增扫幅上下限（控制端正弦 Vpp）、频率点数和幅度点数。默认 12×5＝60 点、幅度范围 0.02–0.32 Vpp，逐幅度、逐频率测量。两轴按对数间隔选点，程序自动量化到可输出的电压步进；每格分别采开环和闭环，因此通常需要数十分钟。可设置 1–64 个频点、1–16 个幅度；单频扫幅将频率上下限设成相同值并将频率点数设为 1。单幅扫描也可将幅度上下限设为相同值、幅度点数设为 1。③ 单幅扫频也使用新的频率点数设置。

热力图是离散测量格子，不填充未测数据。默认颜色为 20log10(闭环基频振幅/开环基频振幅)，负值表示抑制，正值表示放大。灰格为未测或无可用结果，× 表示检出不足或故障中断点。鼠标移到格子显示数值；不超过 144 格时也在格内标数值。限幅、传输失败等会停止扫描，而不会给剩余格子填假数据。

下拉框可切换为「残余基频 / %」：闭环正弦基频峰值除以扣除暗场后的闭环平均光信号，乘 100。这要求在同一会话先完成可靠的噪声测量，保持光路和 PD 增益不变；没有有效暗场就留空。它不是总噪声 RMS，也不包括所有高次谐波；正弦振幅已补偿 CIC 抽取通带衰减。鼠标提示还会显示开环实际相对调制幅度。纵轴为按既有标定换算的控制端设定 Vpp，不能当作光强百分比或 VCO 射频输出的 Vpp。

黑线是基于相邻有效格子插值的 −3 dB 等值线，两种颜色模式都使用同一条抑制比边界。白色菱形是该幅度行从低频开始首次可靠向上穿过 −3 dB 的频率；没有可靠交点则不输出带宽。边界可能不唯一、有闭合区域，也可能在测量范围内完全不存在。在小信号范围，各行交点应近似一致；幅度相关非线性下应报告各幅度条件下的边界，不把它们压成一个唯一的线性带宽。−3 dB 表示振幅比约 0.708，不表示残余波动小于 3% 或 1%。

每次二维扫描新建 `measurements/会话/grid_时间戳/`，逐点更新 `grid.csv`、`grid.json`；各幅度的原始波形和一维结果放在 `amp_码值/`。JSON 保存每幅度的带宽、完成/失败/中止状态和中断格子。停止或异常后保留已测格子并恢复反馈。点「保存图 / 查看数据」保存当前热图与噪声图；选择不同颜色模式后可分别保存。图形等值线只是离散采样间的插值估计，转折附近应缩小范围加密测量。

## 噪声谱、RMS 与抑制比的定义

**RIN**：暗场均值记为 D，带光均值为 M，ADC 波动的单边功率谱为 P(f)，则 RIN(f)=P(f)/(M−D)²，单位 Hz⁻¹；绘图采用 10 log10(RIN)，单位 dBc/Hz。开环曲线表示不纠正时的噪声，闭环曲线表示纠正后的残余噪声。两者必须在相近平均光强下比较；均值变化超过 5% 时程序拒绝给出对比。

**噪声底**：遮光时 PD 电子学与 ADC 的噪声，按带光信号均值归一化。它说明当前测量链能分辨多小的噪声，不包含带光时的散粒噪声。闭环接近噪声底意味着读出受测量底限制，不能宣称实际光强噪声为零。代码不自动扣除噪声底。

**相对 RMS**：sqrt(∫ RIN(f) df)。乘 100 得百分数。积分只使用覆盖的频段，在端点插值，不向未测量区域外推。不同积分范围的 RMS 不能直接比较。

**抑制曲线和带宽**：Q(f)=20 log10[A闭环(f)/A开环(f)]。例如 −20 dB 表示扰动振幅缩小到十分之一，−3 dB 表示缩小到约 0.708，0 dB 表示没有抑制，正值表示放大。这里将从低频抑制区首次向上穿过 −3 dB 的频率定义为「3 dB 扰动抑制带宽」，描述还能至少抑制约一半扰动功率的频率范围。它不是目标跟随传递函数的 −3 dB 带宽，也不自动等于开环增益交越频率。弱于可靠检出阈值的正弦点会标为无效；没有可靠交点就不输出带宽数值。

**开环函数不是开环噪声谱**：在线性化、同一工作点、负反馈约定下，开环传递函数 L(f)=C(f)G(f)H(f) 包含增益和相位，决定纠正强弱和稳定裕量。本程序的输出注入测得 |S(f)|=|1/(1+L(f))|。只有振幅比，不能唯一反推出完整的复数 L，也不能给出相位裕量。

## 论文使用边界

现在 PD 只接反馈 ADC，因此结果是**环内测量**。环内电子噪声可能被反馈抵消在误差信号中，同时转化为真实光噪声；论文若要证明实际输出光的稳定性，仍需要独立环外探测器。报告时写清环内、平均光强、积分范围、采样率、PID 参数以及带宽定义。

多速率噪声谱采用 CIC3 抽取、通带补偿、2048 点 Hann Welch、50% 重叠，各段只保留 3 个频率间隔以上至采样率 1/10。不同频段来自不同时间记录，要求光路统计性质稳定。数字抽取不代替 ADC 之前的模拟抗混叠。正弦拟合含直流与线性漂移，5σ 检出判断的误差模型假设残差近似白噪声；有色噪声下应重复测量评估不确定度。正式报告还应检查扰动幅度减半后抑制曲线一致，以确认小信号条件。

## 固件与非易失启动

FPGA：XC7A35T FGG484-2；本机 Vivado 2023.2。`scripts/build.tcl` 生成 `bitstream/light_lock_top.bit` 和 SPIx4、16 MHz 配置的 `.mcs`。启动默认值：SETPOINT=9843，BIAS=6860，KP_SHIFT=8，KI_SHIFT=12，DIR=1，输出范围 1400–15000，积分限幅 0x00800000，ADC_HALF=4（5 MS/s），ARM=1。Ki 是离散更新增益，依赖采样率。运行中改参数不会自动持久化，掉电后恢复这些启动默认值。

`scripts/program_ram.tcl` 通过指定板卡序列号临时加载；`scripts/program_flash.tcl` 先读取整片 16 MiB Flash 到 `backup/`，备份失败即停止，然后擦除、写入、校验并从 Flash 重启。Vivado 2023.2 型号名为 `mt25ql128-spi-x1_x2_x4`，本机部件表将 `n25q128-3.3v-spi-x1_x2_x4` 列为它的别名；见 [AMD 配置存储器表](https://docs.amd.com/r/2023.2-English/ug908-vivado-programming-debugging/Virtex-7-Configuration-Memory-Devices)。不要将烧录脚本用于未知板卡。

## 测量寄存器

0x30：bit0 正弦使能，bit1 保持 PI 输出与积分，写 bit2 清测量标志；0x31 幅度；0x32/33 32 位相位增量低/高字；0x34 写 bit0 开始、bit1 中止采集；0x35 抽取指数 0–14；0x36 状态 busy/done/clip/fault；0x37 缓存读地址；0x3B 缓存数据（ADC 码×4）；0x3C 保持输出码；0x3D 完成序号；0x3E 完成点数；0x3F 固件标识 0xA623。原 0x38–3A 功率显示寄存器保留。
