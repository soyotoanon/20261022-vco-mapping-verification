# C07 PI 默认参数与时序优化（2026-10-29）

本工程基于 A624 / 5031 最新显示固件，针对状态比较、测试通路和乘法位宽三项进行优化。
保留 50 MHz 系统时钟、5 MHz ADC/PI 更新率及原离散 PI 算法；控制输出不增加寄存级。

上电增益来自 2026-10-27 留板 C07：Kp=9，Ki=17695/32768=0.540008544921875/采样，
寄存器为 0x8900 / 0xC51F；偏置 8198，限幅 1400–15000。
启动目标为 2026-10-29 最近配置的 8476，运行期间仍可串口在线修改；不是永久光功率标定。
boot_profile.json 是本工程启动参数来源，构建时生成 rtl/boot_profile.vh，不能用旧 Flash 读回的 8/12 覆盖它。

## 三项实现

1. i_at_limit 比较已寄存的积分状态，正常更新后晚 20 ns 报告。积分、输出限幅、抗饱和和冻结逻辑仍在原周期执行。
2. 测试关闭时直接旁路注入加法和二次限幅。保持/注入开启或限幅刚写入时使用原限幅路径，保护在线边界更新。
3. 误差为 signed 15 位，绝对值 14 位，两个乘积 29 位；Q9 移位显式保留 23 位。保留正负对称截断及旧移位增益兼容。

0x3F 保持 A624 协议，0x2F 保持 D216 DAC 时序版本，0x38 保持 5031 显示版本。
0x34 读取返回 F129 优化版标识；向 0x34 写入仍是原采集启动/中止接口。
测量数据的 CIC 只在观察支路，不参与反馈。

## 构建、验证与烧录

    D:\mamba\python.exe -B scripts\verify.py
    D:\mamba\python.exe -B scripts\run_build.py
    D:\mamba\python.exe -B scripts\deploy.py --mode ram
    D:\mamba\python.exe -B scripts\deploy.py --mode flash

deploy.py 默认恢复烧录前的目标和闭环/固定输出模式，始终应用 C07 增益；
只有明确选择 --after closed-loop 才把原来的固定输出状态改为闭环。
Flash 模式先备份整个 16 MiB Flash，编程校验并从 Flash 重启，然后在任何增益写入前读取上电参数。
烧录会短暂中断 FPGA 输出；现场处于手动调光时，应先确认允许中断。
调光期间保持的固定 DAC 状态与下一次上电默认闭环状态是两件事。

reference 保留修改前 RTL 用于数值等价对比，不能用来生成现行烧录文件。
build/verification/results.json 是本次真实 XSim 结果；build_summary.json 记录 bit/MCS 哈希与布局布线余量。
这里的时序改善不等于已测得光学闭环带宽提升；真实带宽与阶跃响应需要同工作点测量。
