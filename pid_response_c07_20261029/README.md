# C07 阶跃与平滑接管优化

版本 F22A，寄存器 ABI A624，DAC 接口 D216，显示 5031。基线为已归档的 F129。
保留 C07 的 Kp=9、Ki=17695/32768 每采样、5 MHz 采样率、偏置8198及1400..15000输出范围。

## 行为

- 控制台默认“直接更新”，立即写目标；可显式选择“按速率渐变”。两种模式都将硬件目标步长设为16383，渐变只保留软件一层限速。连接、轮询、切换光路不写控制寄存器。
- 固件上电目标步长为16383，直接目标旁路目标斜坡寄存器，在下一有效采样参与PI计算。写0x2C为1..16382仍可使用FPGA斜坡；0保留旧语义，等同1。
- 固定输出切入PI时，从实际已经锁存的DAC码预置积分，并在切换边沿保持输出。预置I=direction*(DAC-bias)*512；目标跟踪当前ADC后接管。若原DAC超出新输出范围或积分限幅不足，仍以显式限幅为准；C07及DAC8731均在可精确接管范围内。
- 积分的本次增量进入同次输出，去掉旧版积分支路的一采样延迟（200ns）。比例、积分计算和输出仍在同一系统时钟沿提交，无新增反馈流水级。CURRENT_SAMPLE_I=0仅用于基线等价检查；正常顶层使用1。
- 本次积分对应后向矩形离散方式，C07数值增益保留，但与旧版的离散传递函数不同。未饱和且忽略量化时：旧版C(z)=Kp+Ki*z^-1/(1-z^-1)，新版C(z)=Kp+Ki/(1-z^-1)。真实光学带宽与放大峰需要后续实测，不能把200ns积分提前当成整环带宽的已测提升。
- 饱和及积分边界仍然生效。输出饱和状态比较移至已寄存输出，状态比输出晚20ns；反馈抗饱和计算不依赖这个观察标志。

## 接口时序

ADC时钟输出使用独立IOB寄存器，与内部采样相位寄存器同步更新，减少引脚时钟线的内部扇出；未改变5MHz采样频率或数据采样所在的系统时钟沿。

`converter_timing.xdc` 对ADC双边沿复用数据建立生成时钟与min/max输入延迟，去掉原数据总线false_path。ADC采用[AD9248 Rev B](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9248.pdf)的2..6ns器件输出延迟，加外部往返线缆/板线0..4ns预算。该4ns为明确的设计预算，不是测出的板级延迟；时序验收范围为当前5MHz配置。

DAC是按数据变化触发的非周期写入，因此不虚构周期DAC时钟。每根输出线均约束最大/最小延迟，再用实际布线延迟及0/20/40/80ns状态机事件检查建立、保持、WRT到CLK间隔、脉宽。依据[AD9767 Rev G](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9763_9765_9767.pdf)：建立2ns、保持1.5ns、先WRT后CLK时至少间隔2ns、脉宽至少3.5ns。DAC线间外部偏斜预算为2ns，也未冒充现场测量值。

## 验证与构建

运行 `D:\mamba\python.exe -B scripts\verify.py`，七组真实Vivado仿真包括151069组旧模式等价检查、27531组独立PI计算、80种无跳变接管组合、直接目标下一采样生效、本次积分、可选斜坡、ADC/UART及4001组5MSPS DAC写入等。

运行 `D:\mamba\python.exe -B scripts\run_build.py` 完成真实顶层综合、布线、接口检查、bit及mcs生成。任何时序或接口检查失败均不允许发布。`scripts/finalize_routed.tcl`用于本次不改变布局的约束补齐，最终日志为`final-timing.log`。

控制台变更保存在`console/`。19项Python测试以及真实Edge浏览器测试覆盖默认直接更新、显式渐变、读回失败、不干扰测量、旧服务版本拒绝和双通道状态。浏览器通过实际HTTP后端连接内存串口模型，物理硬件写入数为0。

烧录命令：`D:\mamba\python.exe -B scripts\deploy.py --mode flash --after fixed --fixed-code 8731`。
脚本先备份全部Flash，再编程校验、启动并在任何增益写入前核对C07和F22A标识，最后恢复运行目标、固定DAC8731、CTRL8、ARM0。下一次断电重启仍按C07闭环默认启动；固定输出是本次运行状态。
