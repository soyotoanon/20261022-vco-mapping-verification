# 20261022 VCO 映射关系验证

验证 Qosmos DDS V1B **第 8 路 VCO** 的模拟控制输入到 RF 输出幅度的实际映射，
与 DDS 软件中设置的理想映射 `A(V) = b + k·V` 是否一致。

## 背景

光强锁定链路：FPGA(AD9767 DAC) → VCO 控制电压 → DDS RF 幅度 → 功放 → AOM。
2026-10-22 实测发现 DDS 实际输出约为设置映射的 0.76 倍（基准和斜率同比例偏低），
且与 10-21 旧测结果一致（见 `docs/`）。本工具用信号发生器替代 DAC 做独立扫描，
把 DAC 完全摘出链路，定量给出真实映射曲线。

## 接线

- RIGOL DG5352 Pro **CH1** → DDS 第 8 路 VCO 控制输入（1 MΩ，直流耦合，允许 ±5 V）
- DDS 第 8 路 **RF 输出** → RIGOL DSA815 频谱输入（50 Ω）
- 两台仪器 USB 接电脑（NI-VISA）

## 运行

```cmd
pip install -r requirements.txt
python vco_mapping_app.py
```

或直接双击 `run_app.cmd`。

界面操作：自动识别 → 连接 → 填理想映射参数（默认 b=0.207, k=0.0094，
即 10-22 下发到 DDS 的映射）→ 开始扫描。扫描范围程序硬限幅 ±4.5 V
（VCO 输入允许 ±5 V）。结束或手动停止都会关闭信号发生器输出。

无界面自检（5 点快扫）：

```cmd
python vco_mapping_app.py --cli --start -1 --stop 1 --step 0.5
```

## 读数口径

- 实测值：频谱仪读 100 MHz 载波 dBm，按 50 Ω 换算成 **Vpp**（P[mW] = 2.5 × Vpp²）。
- 理想线：DDS 设置 `A(V) = b + k·V` 按**峰值**解释，图中画 `Vpp = 2(b+kV)`。
- 拟合：实测点直线拟合后与理想线对比，给出斜率/截距偏差百分比和 R²。

## 输出

`outputs/<时间戳>/`：

- `vco_mapping_sweep.csv` — 每点：设定电压、回读电压、载波频率、dBm、Vpp、理想值、残差
- `vco_mapping_fit.json` — 拟合斜率/截距、R²、与设置的偏差、仪器 ID、时间戳
- `vco_mapping_plot.png` — 曲线图（GUI 导出时）

## 已确认的既有事实（2026-10-22）

- DAC(AD9767 模块)码→电压：实测 6.533e-4 V/码、零点 8198 码（两点标定，万用表直流档）
- VCO 输入悬空电压 +1.439 V（1 MΩ 上拉），驱动状态下影响 ≤ 73 µV，可忽略
- 调频测试（1 MHz/V）：载波随控制电压移动，模拟控制通路正常
- 载荷效应可忽略：51 Ω 源阻抗对 1 MΩ / 10 MΩ 负载差 < 0.005%
