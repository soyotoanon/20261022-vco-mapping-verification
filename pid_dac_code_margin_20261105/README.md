# FPGA 光强控制：DAC 两端各留 100 码

本版本基于 F129 / A624，将两路 14 位 DAC 的输出码限定在 **100～16283**。14 位满量程为 0～16383；两侧各留 100 码。版本标识寄存器 0x34 返回 `F100`。

## 控制行为

- PI、固定输出、测试波形、扫描和双通道 ADC 直通，最终送到两路 DAC 的数值都经过限幅。实际锁存码通过现有状态接口读回。
- PI 输出上下限寄存器 0x1E、0x1F 默认是 100、16283，可在线设置更窄范围。写入超出硬边界的值会被截到硬边界，PI 抗积分饱和使用同一组读回限幅。
- 保留 F129 的 PI 算法与默认 C07 增益、目标功率在线设置、采样率和显示功能；ADC 时钟输出采用已验证的 F22A 引脚寄存器实现。调整 VCO 映射后需要重新验证 PI 稳定性。
- 继承 F129 的上电配置：默认启用并武装 PI。编程或重启会中断输出；不得把此固件误认为开机固定输出模式。

## 数字码和模拟电压

历史两点直流标定为 `V≈(D−8198)×0.0006533 V`。按此估算，100～16283 约对应 **−5.290～+5.282 V**，不是 ±5.0 V。该公式不等于实测端点电压，也不能保证电压瞬态；编程配置、复位或掉电期间数字逻辑不能保证模拟输出范围。连接的 VCO 接口能否承受这一范围尚未确认。

## VCO 参考设置

第 8 路、100 MHz：调频斜率 0 MHz/V，0 V 处振幅参数 0.1786 V，调幅斜率 0.0357 V/V。按照先前的 `实际峰值≈界面设定×0.77` 估算，映射表的 −5～+5 V 对应约 0～550 mVpp；100～16283 两端估计超出了这个表的输入电压范围，DDS 如何处理超界值尚未验证。0 mVpp 测量点是 RF 关闭状态，不能据此保证 DDS 零设定能够完全关光。

## 验证与状态

`python scripts/verify.py` 运行 XSim：逐一检查全部 16384 个输入码、两路 DAC、PI/固定/波形/扫描/直通路径、限幅寄存器读写及原有 PI 算法。`python scripts/run_build.py` 执行 Vivado 综合和布线。

本版 8 组仿真通过，Vivado 内部 WNS 0.419 ns、WHS 0.047 ns；5 MHz ADC 接口建立/保持裕量为 1.090/4.701 ns，两路 DAC 接口预算通过（板外延迟为假设，非实测）。固件 SHA-256：`fa934a9a249e98db6f498e165090fc99ba29ac4f39ecdb862ad5287a0b224f12`。**尚未连接 FPGA、烧录、测量 DAC 端电压或实测光路**。现场需要确认 VCO 端口允许电压，并以万用表或示波器实测端点后才能验证模拟范围。保留原 F129 版本作为回退依据。
